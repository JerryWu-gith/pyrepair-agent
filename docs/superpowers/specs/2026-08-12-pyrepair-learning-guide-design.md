# PyRepair Agent 十天实战学习手册 PDF 设计

## 目标

为已经掌握 Python 基础、正在学习 HelloAgent 第 7 章、尚不熟悉 Git 工作流的学习者，制作一份可以按天执行的中文项目学习手册。手册不要求逐行背诵源码，而是帮助学习者建立完整调用链，能够运行、解释、调试、改进和展示 PyRepair Agent。

## 交付物

- 最终 PDF：`output/pdf/pyrepair-agent-10-day-learning-guide.pdf`
- 可维护的中文正文：`docs/pyrepair-learning-guide.md`
- 可重复执行的 PDF 构建脚本：`scripts/build_learning_pdf.py`
- 中间渲染文件只放在 `tmp/pdfs/`，交付前清理。

## 内容结构

1. 使用说明与学习目标
2. 项目全景：问题、边界、核心流程和术语
3. 环境重建与命令逐段解释
4. 十天学习路线，每天 4-6 小时
5. 按调用链阅读 15 个核心模块
6. Repair Agent Tool Calling 循环
7. Policy、Review、Verifier 三层安全门
8. FakeLLM、离线测试、Live Test 和 Benchmark 的区别
9. Git 最小知识与本项目练习方式
10. 亲手改进 pytest 9 解析器的练习方案
11. 调试手册与常见错误
12. 项目讲解模板、简历表述和面试追问
13. 10 天验收表与后续 30 天进阶路线

## 每日章节模板

每一天保持相同结构，降低学习负担：

- 当天目标
- 必须理解的概念
- 阅读文件及顺序
- 命令与逐段解释
- 动手任务
- 自测问题
- 完成标准
- 学习记录区

## 教学原则

- 从一次真实 CLI 调用沿调用链学习，不按文件名机械阅读。
- 源码与对应测试成对阅读。
- 明确区分 LLM 概率判断与 Python 确定性规则。
- 每个概念都落实到本项目中的具体文件、类、函数或产物。
- 对暂时不需要的知识明确标注“可以后学”，避免扩大前置要求。
- 所有 Git 操作先在本地练习，不要求立即使用 Pull Request。
- 对真实评测结果保持诚实，解释 13/15、86.7% 和两个技术失败。

## 版式

- A4 纵向，适合屏幕阅读和打印。
- 中文字体优先使用 Windows 的微软雅黑或等价 CJK 字体。
- 深蓝主色、青绿色强调色，正文保持高对比度。
- 封面、目录、章节页、正文、表格、代码框和提示框具有统一层级。
- 页眉显示手册名称，页脚显示页码。
- 代码命令使用等宽字体；长路径和长命令必须自动换行或拆行，不能越界。
- 控制在约 25-35 页；内容优先于强行压缩页数。

## 验收标准

- PDF 能正常打开，页数与目录合理。
- 中文无乱码、无黑方块，代码和路径可读。
- 每一页无裁切、重叠、孤立标题或明显大块空白。
- 所有本地文件路径和命令与当前仓库结构一致。
- 10 天计划每天都有动手任务、自测问题和完成标准。
- 包含至少一张项目流程图、一个模块阅读表和一个测试层次对照表。
- 使用文本提取检查关键章节完整，使用逐页 PNG 渲染检查视觉布局。

## 不包含的内容

- 不逐行复述全部源码。
- 不承诺学习十天后成为通用 Agent 专家。
- 不把 DeepSeek V4 Flash 的端到端成功率称为模型准确率。
- 不要求在学习手册阶段自动创建 GitHub PR 或启用自动修复提交。
